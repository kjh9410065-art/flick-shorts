# FLiCK Shorts

내 영상을 브라우저에서 쇼츠 규격으로 자동 편집하는 MVP입니다.

## 현재 기능
- 영상 업로드 및 드래그 앤 드롭
- 9:16 세로 화면 자동 크롭
- 15/30/45초 및 원본 길이 선택
- 가로 영상 크롭 위치 선택
- 화면 문구 미리보기 및 렌더링
- 사용자 배경음악 합성
- MP4 렌더링 및 다운로드
- 서버 업로드 없이 브라우저에서 FFmpeg WebAssembly로 처리

## 다음 단계
1. 자동 자막(STT)
2. 비트 기반 컷 전환
3. 템플릿 효과
4. AI TTS
5. 이미지 생성
6. AI 영상 생성
7. 계정/크레딧/결제

## 주의
첫 렌더링 시 FFmpeg WebAssembly 파일을 CDN에서 내려받습니다. 긴 영상이나 고해상도 영상은 브라우저 메모리 한계로 실패할 수 있습니다.

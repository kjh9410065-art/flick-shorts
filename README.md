# FLiCK Shorts

내 영상을 브라우저에서 쇼츠 규격으로 자동 편집하는 브라우저 기반 제작기입니다.

## 현재 구현

### 1단계 · 기본 쇼츠 제작
- 영상 업로드 및 드래그 앤 드롭
- 9:16 세로 화면 자동 크롭
- 15/30/45초 및 원본 길이 선택
- 처음/가운데/마지막 구간 자동 컷
- 화면 문구 오버레이
- 사용자 배경음악 합성 및 반복 재생
- MP4 렌더링 및 다운로드
- FFmpeg WebAssembly 기반 브라우저 처리

### 4단계 · AI 음성
- Supertonic TTS 기반 브라우저 AI 음성 생성
- 한국어/영어/스페인어/포르투갈어/프랑스어 지원
- 여성/남성 음성 스타일 선택
- 말하기 속도 조절
- 생성 음성 미리듣기
- AI 음성만 사용하거나 배경음악/원본 오디오와 믹스
- 음성 파일은 서버 업로드 없이 브라우저에서 생성 및 처리

### 3단계 · 비트 기반 자동 편집
- Web Audio API로 음악 에너지 피크 분석
- 비트 후보 지점 자동 검출
- 영상 구간을 비트 경계에 맞춰 분할
- FFmpeg concat으로 여러 컷을 하나의 쇼츠로 연결
- 배경음악이 없으면 영상 원본 오디오를 분석

### 2단계 · STT 자동 자막
- 선택한 쇼츠 구간의 오디오 추출
- Transformers.js + Whisper 기반 음성 인식
- 자동 언어 감지 또는 한국어/영어/일본어/중국어 선택
- 시간대가 포함된 자막 생성
- 생성된 자막 문구 직접 수정
- Noto Sans KR 폰트를 이용한 MP4 자막 합성

## 개발 순서

1. 영상 업로드 → 9:16 → 자동 컷 → 음악 → 자막 → MP4
2. STT 자동 자막
3. 비트 기반 자동 편집
4. AI 음성 ← 구현
5. 이미지 생성
6. AI 영상 생성

## 처리 방식

영상과 음성은 기본적으로 브라우저 안에서 처리합니다. FFmpeg WebAssembly가 영상 편집을 담당하고, STT는 브라우저에서 Whisper 모델을 실행합니다. 최초 사용 시 CDN과 모델 파일을 내려받는 시간이 필요합니다.

## 주의

긴 영상이나 고해상도 영상은 브라우저 메모리 한계로 실패할 수 있습니다. Whisper 모델 역시 최초 다운로드와 브라우저 메모리를 사용하므로 첫 자막 생성은 시간이 걸릴 수 있습니다.


## AI 음성 모델

4단계는 `onnx-community/Supertonic-TTS-2-ONNX`를 브라우저에서 실행합니다. 모델은 OpenRAIL 계열 라이선스를 사용하므로 실제 상업 배포 전 최신 라이선스와 사용 제한을 확인해야 합니다.

### 5단계 · AI 이미지 생성
- 프롬프트 기반 이미지 생성
- 9:16 / 1:1 / 16:9 비율 선택
- FLUX/Turbo 모델 선택
- 생성 이미지 미리보기 및 다운로드
- API 키는 브라우저 localStorage에만 저장
- Pollinations 이미지 API 연결


### 이미지 생성 주의사항
5단계는 Pollinations 이미지 API를 사용합니다. 현재 API는 인증이 필요하며, 브라우저 앱에서는 사용자가 직접 API 키를 연결하는 방식으로 구현했습니다. 실제 서비스 배포 전에는 BYOP/OAuth 또는 별도 서버 프록시를 적용하는 것을 권장합니다.
